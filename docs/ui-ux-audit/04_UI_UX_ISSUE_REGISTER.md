# Prioritized UI/UX Issue Register

**Product:** AstroLogic / Nakshatra Labs  
**Version:** 2.0.0  
**Priority Classification:**
- **P0 — Critical Usability / Functional Blocker:** Breaks primary task completion, yields HTTP errors, or completely misleads the user.
- **P1 — High-Impact Issue:** Major UX friction, layout breakage, missing navigation, or data loss that significantly impairs user satisfaction.
- **P2 — Moderate Improvement:** Styling inconsistency, missing secondary feedback, awkward touch interaction, or minor layout shift.
- **P3 — Minor Polish:** Micro-copy cleanup, code deprecation, or aesthetic alignment.
